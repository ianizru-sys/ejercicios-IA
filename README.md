# ejercicios-IA
UT02 - Tarea 4 - Usando a la IA como profesor

📝 Ejercicio 1 — Contar vocales
Crea una función contarVocales(string $texto): int que reciba un texto y devuelva cuántas vocales tiene.


📝 Ejercicio 2 — Número mayor de un array
Crea una función mayorDeArray(array $numeros): int que devuelva el número más grande sin usar max(). Hazlo tú mismo con un bucle.


📝 Ejercicio 3 — Invertir un texto
Crea una función invertir(string $texto): string que devuelva el texto al revés sin usar strrev().


📝 Ejercicio 4 — Sumar solo los pares
Crea una función sumarPares(array $numeros): int que sume únicamente los números pares del array.
